ENFOQUE DEL PROYECTO

Una herramienta creada desde una necesidad real

El proyecto busca transformar tareas que habitualmente se realizan de forma separada en un flujo de trabajo organizado y fácil de consultar.

01

ORGANIZACIÓN

Centralizar la información

Agenda, pacientes, sesiones y movimientos financieros podrán consultarse desde una misma aplicación.

02

SEGUIMIENTO

Mantener un registro claro

El sistema permitirá conocer el estado de las sesiones, pagos y reservas sin depender de registros dispersos.

03

ESCALABILIDAD

Construir por etapas

La arquitectura actual deja preparada la aplicación para incorporar base de datos, autenticación y API.
